# taobao-user-behavior-analysis
淘宝用户购物行为数据分析项目
基于阿里天池淘宝用户行为数据集的电商用户行为分析项目，使用 MySQL 完成数据清洗与多维度分析，Excel 完成可视化，输出完整分析报告。

## 项目背景

以淘宝平台真实用户行为数据为研究对象，分析用户在电商平台上的行为模式与转化路径，为运营决策提供数据支撑。

## 数据说明

- 数据来源：阿里天池 · 淘宝用户行为数据集（UserBehavior.csv）
- 数据规模：原始数据约 1 亿条，采用蓄水池抽样法抽取 10 万条，清洗后有效记录 99,948 条
- 时间范围：2017年11月25日 — 2017年12月3日（共9天）
- 行为类型：浏览（pv）、加购（cart）、收藏（fav）、购买（buy）

## 分析维度

1. 用户行为类型分布
2. 每日活跃度趋势
3. 每小时活跃度分布
4. 用户转化漏斗分析
5. 用户复购行为分布
6. 用户价值分层
7. 热门商品类目 TOP10

## 核心结论

- 浏览行为占绝对主导（89.7%），购买行为仅占 1.99%，浏览到购买转化空间巨大
- 周末（12月2-3日）UV/PV 明显高于工作日，为活跃高峰
- 用户活跃集中在晚间 21-22 点，凌晨 2-5 点为低谷
- 浏览→加购流失率 93.5%，但加购→购买转化率高达 36.9%，加购是极强的高意向信号
- 普通浏览用户占比 97.8%，用户促活与留存是核心痛点
- 类目 1464116 为热门类目，购买次数最高（47次）

## 技术栈

- 数据库：MySQL
- 数据处理：SQL 查询分析
- 可视化：Excel
- 分析流程：数据获取 → 数据清洗 → 多维度分析 → 可视化呈现 → 报告撰写

## 数据局限性

- 数据集仅包含 9 天行为数据，时间窗口较短，复购行为可能存在系统性低估
- 基于 10 万条随机抽样数据，结论适用于该样本范围
- 商品类目 ID 为脱敏编码，无法对应真实商品名称
